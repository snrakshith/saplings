# Starter frontend

Start the frontend and API together with `pnpm dev` from the parent Starter directory.

The React entry point is `src/main.tsx`. Feature folders contain identity, the dashboard, SDK catalog, providers, and product services. Shared API calls and the Saplings Hooks integration live in `src/lib/api.ts`. The `test` directory holds the Chromium journeys.

See the [Starter guide](../README.md) for the local and durable profiles.
