# @sapling/backend-quality v0.5.0
Development-only backend quality orchestration. See ../../docs/BACKEND_QUALITY.md for full configuration, profiles and limitations. All 15 categories ship together; engines may need installation and application-specific tests. No automatic traffic at SDK initialization. Use Node 22.18+ (native type stripping) or a compiled config / `node --import tsx` for TypeScript config imports.
