# Source provenance

Murphi UI source provided in `murphui.zip`: `src/theme/{colors,palette,typography,spacing,breakpoints,types}` adapted into this package. Murphi README describes MIT licensing, but the supplied Murphi archive did not contain a separate LICENSE file. Confirm ownership and license notice before public redistribution. Xlox UI archive was used for package architecture inspiration; its MIT license remains in its original repository. No Xlox UI source files were directly copied into this package.
