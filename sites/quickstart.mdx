## Set up Node.js

Use Node.js 26.13.1 or a newer 26.x release. Create a project and install the published SDK.

```bash
mkdir saplings-demo
cd saplings-demo
npm init --yes
npm install @saplings/sdk
```

## Create a tenant-scoped project

Save this file as `quickstart.mts`. The actor and in-memory store are local fixtures.

```ts
import { createSapling, defineSaplingConfig, type ActorContext } from '@saplings/sdk';

const config = defineSaplingConfig({ app: { id: 'saplings-demo', environment: 'development' } });
const sdk = createSapling(config);

const context: ActorContext = {
  tenantId: 'demo',
  actorId: 'user-1',
  permissions: ['projects:write', 'projects:read'],
};

const record = await sdk.projects.create(context, { name: 'First project' });
const saved = await sdk.projects.get(context, record.id);
console.log(saved?.name);
```

```bash
node quickstart.mts
```

The command prints `First project`. Record IDs and timestamps are generated by the SDK. Data is stored only for the lifetime of this process.

## Add an HTTP application

Derive the actor from a verified request identity in your server. Use [SDK configuration](/sdk/configuration) for the context hook and provider interfaces, then use the [API reference](/packages/sdk) to choose operations. The [Saplings Starter guide](https://github.com/snrakshith/saplings/blob/main/starter/README.md) shows how to fork the full-stack application and run it locally or with PostgreSQL.
